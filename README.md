# wizui

A React component library. Nuxt UI’s look and API — install the package, pass data, ship.

No Radix. No copy-paste. Native HTML.

## Install

```bash
npm i wizui
```

```css
@import "tailwindcss";
@import "wizui/theme.css";
```

```tsx
import { WButton } from "wizui"

<WButton color="primary" variant="subtle" icon="plus">
  New
</WButton>
```

Same props everywhere: `color`, `variant`, `size`, `icon`, `className`.

## Components

Button · Badge · Alert · Card · Input · Textarea · Checkbox · Switch · Radio Group · Form Field · Modal · Dropdown · Separator · Kbd · Skeleton
